# Expected decoded values

Generated by `scripts/generate_examples.py`; do not edit by hand. `examples/expected/<name>.json` holds the same
data in machine-readable form. Scalar values are the pre-encoding values; a conforming decoder must reproduce them within
the stated tolerance (half of one quantisation step). Rows count from the north edge, columns from the west edge, both 0-based.
